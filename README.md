## Facebook Page Posts Viewer

تطبيق ويب بسيط يعرض منشورات أي صفحة فيسبوك (نص/صور/فيديو) باستخدام Access Token عبر Facebook Graph API.

### التشغيل

```bash
npm start
```

ثم افتح:

- `http://localhost:3000`

### الاستخدام

1. أدخل **Page ID**.
2. أدخل **Access Token** صالح يمتلك صلاحيات قراءة منشورات الصفحة.
3. اضغط **عرض المنشورات**.

### ملاحظات

- بعض الصفحات تتطلب توكن بصلاحيات خاصة (مثل `pages_read_engagement` أو صلاحيات أخرى حسب إعدادات Meta).
- التطبيق لا يخزن التوكن؛ يتم استخدامه فقط في الطلب المباشر إلى الخادم.
